Android 音乐均衡器开发计划
一、项目目标
开发一款 Android 独立音乐均衡器，第一阶段目标是：
	•	对其他音乐 App 的音频进行 EQ
	•	支持系统音频输出
	•	支持蓝牙耳机
	•	支持手机扬声器
	•	支持 10/15/20 Band Graphic EQ
	•	支持 Parametric EQ
	•	支持 Preamp
	•	支持 Limiter
	•	支持 EQ Preset
	•	支持实时频谱
	•	支持不同播放器/设备独立配置
最终目标：
做成类似 Poweramp Equalizer / Wavelet 的系统级 Android 音频增强工具。

十八、建议的实际开发顺序
如果你准备使用 AI Coding Agent 辅助开发，我甚至建议把任务拆成下面 20 个 Task：
01. 创建 Android Kotlin + Compose 项目

02. 配置 NDK + CMake

03. 建立 Kotlin ↔ JNI ↔ C++ 通信

04. 实现 BiquadFilter

05. 实现 Peaking EQ

06. 实现 Graphic EQ

07. 实现 Preamp

08. 实现 Limiter

09. 建立 DSPChain

10. 实现 AudioEffectManager

11. 实现 AudioSessionManager

12. 完成 Spotify 音频链路验证

13. 完成 Bluetooth 音频验证

14. 创建 EQ Compose UI

15. 实现实时 EQ 曲线

16. 实现 Preset 系统

17. 实现 FFT Spectrum

18. 实现 Device Profile

19. 实现 Per-App Profile

20. 全平台兼容性测试
最关键的是 Task 12。
如果：
Spotify
 ↓
你的 EQ
 ↓
Bluetooth
能够稳定工作，那么后面的 UI、Preset、FFT、设备配置基本都是工程问题。
如果这条链路做不到，那么即使 UI 做得再漂亮，也很难成为真正的 系统级 Android Equalizer。
如果你打算直接让 AI（Claude Code / Codex / Cursor 等）帮你写这个项目，我建议下一步不要直接让 AI “开发一个 Android 均衡器”，而是把上面的计划进一步拆成一份 完整的 AI 开发 Prompt + 项目目录 + C++ DSP 接口设计 + Kotlin 接口设计 + 数据库 Schema + 每个 Task 的验收标准。这样 AI 会更容易持续开发，而不是第一轮就把项目架构做乱。
